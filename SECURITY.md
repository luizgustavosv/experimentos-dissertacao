# Security Policy

This repository supports academic research code. It is not intended to process untrusted files as a hosted service.

## Reporting a Vulnerability

Before opening a public issue, report suspected secrets, private data exposure, or security-sensitive bugs privately to the repository owner through GitHub private contact channels.

Do not include full credentials, private keys, dataset files, or personal data in public issues or pull requests. If a credential was committed at any point, treat it as compromised and rotate it outside this repository.

## Scope

Relevant reports include leaked credentials, accidental publication of private data, unsafe handling of archives or checkpoints, and GitHub Actions configurations that could expose secrets.

Scientific disagreements, reproducibility questions, and ordinary bugs should be reported through normal issues after the repository is public.
